# لوحة أسعار Ajcoin

صفحة ثابتة لتطبيق تيليجرام المصغّر (@Ajcoinbot). تعرض أسعار العملات الرئيسية مع تحديث تلقائي وخطوط Sparkline.

- الواجهة عربية، من اليمين لليسار، بتصميم داكن يتبع ألوان تيليجرام إن فُتحت داخل التطبيق.
- الأسعار تُجلب من المتصفح مباشرة (بدون خادم وسيط) بهذا الترتيب: **Gate.io** ثم **CoinGecko** ثم **Binance** (`data-api.binance.vision`) إذا تعذّر المصدر السابق.
- الأرقام للعرض فقط وليست نصيحة استثمارية. لا تتضمن الصفحة أي تداول أو مفاتيح.

تعمّل الصفحة عبر GitHub Pages:
