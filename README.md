# المحفظة والتداول — Ajcoin Mini App

صفحة ثابتة لتطبيق تيليجرام المصغّر (@Ajcoinbot). لا تحتوي على مفاتيح أو أرصدة أو عناوين إيداع.

التبويبات:

- **الأسعار**: أسعار حية مع Sparkline. المصدر من المتصفح مباشرة: Gate.io ثم CoinGecko ثم Binance (`data-api.binance.vision`).
- **تداول**: اختيار زوج USDT (BTC, ETH, SOL, BNB, XRP, TON, DOGE) وشراء أو بيع. يُرسل الطلب إلى البوت عبر `Telegram.WebApp.sendData` ويحتاج تأكيد ✅ في المحادثة قبل أي تنفيذ.
- **المحفظة**: طلب عرض الرصيد أو عنوان الإيداع (يُجلب من البوت بعد التحقق). السحب غير متاح من الصفحة أو البوت — استخدم تطبيق Gate.io للسحب.

`sendData` يعمل فقط إذا فُتحت الصفحة من زر لوحة الكتابة «📱 المحفظة والتداول» (`?mode=wallet`). زر قائمة البوت يفتح اللوحة للعرض. إن تعذّر الإرسال تظهر عبارة: «افتح من زر المحفظة والتداول في لوحة الكتابة».
